# Against the Fraud Daily

A daily ~12-minute podcast for attorneys and anyone following whistleblower cases and U.S. government fraud: the case of the day, one FCA practice note, and the technology that finds and proves the fraud. Hosted by Alex and Jordan.

## Repo layout

- `episodes/` — one note per episode: summary, cases, practice note, tech angle, and reference links.
- `transcripts/` — full word-for-word transcript of every episode.
- `catalog.json` — machine-readable episode catalog (guid, title, date, duration, audio URL, transcript path).
- `docs/` — notes for automation (e.g. the brief for a coding agent that builds a catalog from the RSS feed).

## Ground rules

- Every settlement discussed is allegations only unless a court or agency has determined otherwise; there has been no determination of liability in a civil settlement.
- Facts are verified against 2+ reputable sources (DOJ releases, major news outlets, court records). No sealed, confidential, or non-public case material is used.
